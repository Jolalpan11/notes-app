# Notes App

A simple notes app built with Node.js, Express, MongoDB, and vanilla JavaScript.

## Features
- Create notes with a title and text.
- View saved notes.
- Delete notes.
- Keep notes saved in MongoDB between visits.

## Run locally
1. Install Node.js and MongoDB.
2. Open a terminal in the project folder.
3. Run `npm install` to install the required packages.
4. Copy `.env.example` to `.env` and check the database address.
5. Make sure MongoDB is running.
6. Run `node server.js` to start the app.
7. Open http://localhost:3000 in your browser.
